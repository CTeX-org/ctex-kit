% #1037 的两个守卫用例。二者都**不含任何装饰命令的排版问题**，
% 而是在第一版修复下直接编译报错；正确实现下零错误。
%
% A: 装饰之外重定义 \  （nath、morehype 等宏包会这么做）
%    第一版修复只依赖 \xeCJK_if_ulem_patch:TF，会在没有 \UL@box
%    打开的列表里执行 \UL@stop，报 Too many }'s。
%
% B: 行内公式里的装饰命令之后
%    公式路径经 \UL@onmath/\UL@onin 结束，不复位装饰 stream 布尔，
%    因此「布尔为真但片段盒已关闭」，同样执行悬空的 \UL@stop。
\documentclass{article}
\usepackage[LoadFandol]{xeCJK}
\usepackage{xeCJKfntef}
\makeatletter
\def\ {\leavevmode\nobreak\ }%  模拟 nath/morehype 对 \  的重定义
\makeatother
\begin{document}

A: 中 abc 文

B: $\CJKunderline{中}\mbox{中 abc 文}$

\end{document}

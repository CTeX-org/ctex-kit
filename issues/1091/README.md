# Issue #1091 资产

用 `\CJKunderline` 等线型命令排填空线时，命令前的空格跑到装饰线后面，
结尾还多出一段装饰线；正文以全角标点开头或结尾时，边界间距也不对。

根因：ulem 用 `\UL@end *` 标记正文结束，结束时在一个随即丢弃的片段盒里
排出定界符 `*`。这个 `*` 不出现在页面上，但会触发 XeTeX interchar 转换，
命令边界 capture 因此把它当成正文中的西文字符。正文没有字符或以全角标点
开头时，左边界被补到装饰末尾；正文以全角标点结尾时，右边界按西文处理。

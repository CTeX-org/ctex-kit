# 决策：分别处理 fntef 的正文、字间距和命令端点

## 背景

`xeCJKfntef` 基于 `ulem` 把正文拆成多个装饰片段，并用 leaders 在每个片段内重复
装饰单元。默认波浪线原来来自固定的 6pt `lasy` 字体，斜删除线来自当前数学字体；
它们的单元宽度与正文字号、全角字宽和伸缩后的 `CJKglue` 没有稳定比例。因此，
波浪线和斜删除线在普通正文、相邻带 `-` 的命令、标点和换行处可能局部过密、断开
或左右不均。

曾尝试把 `\UL@pixel` 清零，再为带 `-` 的形式手工恢复命令两端的空白。这会改变
`ulem` 原有的装饰区间、余量分配和端点语义，导致装饰总长度缩短、相对正文偏移，
相邻带 `-` 命令之间还会出现明显断口。后续的 `1em/3` 图案加原 leaders 选择，以及
`1em/4` 图案加普通 `\leaders`，也只能分别缓解缩放或相位问题，不能同时处理正文、
实际伸缩的中文字间距和两种命令端点。这些均为已经被替换的中间路线。

## 决定

保留修复前已经正确的装饰总长度、相对正文的居中方式，以及普通形式和带 `-` 形式
各自的端点语义；正文片段、`CJKglue` 和命令外端点则分别处理：

- 默认波浪和斜删除线都由 `l3draw` 绘制宽 `1em/4` 的图案，振幅、高度和线宽随
  当前 `em` 缩放；常规全角字符每字约容纳四个单元，斜删除线不再依赖数学字体。
- 两个默认图案都用 `\cleaders` 排列正文片段，使图案相对片段居中，外层水平偏移
  不改变起始相位。周期路径把 `\UL@pixel` 减半，使整数周期的正文片段实际落在
  正文边界。
- 普通形式在正文左右各画半个单元，保留既有装饰总长度和对称居中；带 `-` 形式
  不画这两个外端点，图案恰好落在正文边界。两种形式不改变命令自身宽度。
- `CJKglue` 不再重复排列周期盒子。波浪单元从波峰开始并在波峰结束，胶水区域用
  同线宽的水平线连接两侧波峰；斜删除线在胶水区域只保留实际空白，使相邻斜线的
  节距增加实际胶水宽度。胶水的伸缩与断行能力不变。
- 这项胶水专用处理只进入 `\@@_ulem_ccglue:`。正文中的 `\quad` 和一般显式
  `\hskip` 仍由 `ulem` 原路径绘制装饰；标点与 `CJKecglue` 也不进入该分支。
- `underwave/symbol` 只有保持默认值时才进入上述周期路径。用户自定义波浪符号继续
  使用历史 `\xleaders` 路径，其尺寸、相位和视觉结果由使用者检查。

## 验证

测试按职责分层：

1. `fntef-underline-offset` 使用真正的 `l3draw` 装饰盒，固定 8pt、10.53937pt 和
   15pt 下的宽、高、深，证明单元宽度确为 `1em/4` 且随字号缩放。
2. 节点和换行回归把完整绘图临时替换为同尺寸的轻量规则盒子，固定默认与自定义
   leader 类型、装饰区间、两种端点形式、相邻命令、标点、换行、实际伸缩的
   `CJKglue`，以及普通 `\quad` 仍被装饰。替身避免把大量 PDF 绘图 special 写入
   `.tlg`，但不能证明页面上的相位和接点坐标。
3. `fntef-phase01` 先从 XDV 生成不压缩内容流的 PDF，再由
   `testfiles/support/fntef-phase-check.lua` 读取标记与图案盒子的实际横坐标。它固定
   外层水平偏移下的相位、普通与带 `-` 形式的端点、固定和伸缩 `CJKglue` 两侧节距、
   相邻带 `-` 命令的连接，以及普通显式跳距仍被装饰。
4. 从手册提取的精确单页 MWE 检查实际字体、字号、示例文字和伸缩胶水下的波浪形状、
   斜线密度、连接、装饰长度和居中；整本文档构建只验证集成路径。

从源码树验证生成宏包时，必须在编译日志中核对实际加载的 `xeCJKfntef.sty` 路径。
系统 TeX Live 中的同名旧文件不能作为当前工作树实现的证据。

## 与 #1017 的职责边界

本决定只处理默认装饰图案的几何和随字号缩放。#1017 在共享装饰盒中使用空
`ActualText`，并在最小范围暂停 tagging，负责 PDF 的复制、搜索和文本提取语义；
boundary capture 的暂停／恢复负责 xeCJK 命令边界状态。三条路径解决不同问题，
都要保留各自的回归。

固定提交上的独立审查还分别编译了普通 PDF 和启用 tagging 的同一最小样例。两种
PDF 经 `pdftotext -raw` 与 `-layout` 提取时都只包含正文，说明本次几何改动没有破坏
#1017 建立的文本语义隔离。

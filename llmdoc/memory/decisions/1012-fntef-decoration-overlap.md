# 决策：普通 leaders 共享相位，首末裁切控制可见范围

## 背景

`xeCJKfntef` 基于 `ulem` 把正文拆成多个装饰片段，并用 leaders 重复装饰单元。
默认波浪线原来来自固定的 6pt `lasy` 字体，斜删除线来自当前数学字体；它们的
单元宽度与正文字号、全角字宽和伸缩后的 `CJKglue` 没有稳定比例。因此，波浪线和
斜删除线在普通正文、相邻带 `-` 的命令、标点和换行处可能局部过密、断开或左右不均。

先后试过清零 `\UL@pixel`、`1em/3` 图案加原 leaders、朴素的 `1em/4` 图案加普通
`\leaders`，以及 `\cleaders` 加胶水专用图形。前两种会破坏装饰长度或继续重新分配
相位；朴素的普通 `\leaders` 没有精确端点和正宽断口；`\cleaders` 会让各片段重新
选择相位，并在中文字间距中画出不属于原图案的水平线。这些均为已经被替换的中间路线。

## 决定

方案必须同时满足三项约束：同一行的波浪／斜线片段共享相位；相邻带 `-` 命令之间
有明确断口；整段装饰始终相对正文居中。实现把相位、可见范围和断行接点分别处理：

- 默认波浪和斜删除线都由 `l3draw` 绘制宽 `1em/4` 的图案，尺寸和线宽随当前 `em`
  缩放；常规全角字符每字约容纳四个单元，斜删除线不再依赖数学字体。
- 两个默认图案都用普通 `\leaders`。正文片段、固定或伸缩后的 `CJKglue` 以及换行
  后的片段都落在同一个相位网格上；`\leaders` 只承担这一项职责。
- 首段和真正的末段使用局部 PDF 裁切。底层 leaders 区间向两侧各扩展一个完整周期，
  可见范围再精确限制为：普通形式相对正文左右各外伸半周期，带 `-` 形式左右各内缩
  半周期。两种形式的命令宽度、正文宽度和断行均不改变；相邻带 `-` 命令之间因此恰有
  一个完整周期的可见断口。
- 带 `-` 形式首段后的第一个 `CJKglue` 在断点两侧各放一个净宽为零的半周期连接。
  不换行时两半拼成连续周期；换行时分别止于上一行末尾和下一行开头。裁切内部的
  leaders 前使用 penalty 10000，保证 PDF 的 `gsave`／`grestore` 不会被拆到两行。
- `ulem` 在命令末尾会追加随后删除的语法空格。实现以 `\UL@spfactor` 哨兵辨认真正
  的后续片段，单片段命令只由首段裁切一次；末段重画只在确有后续片段时发生。
- 正文中的 `\quad`、一般显式 `\hskip` 和 `CJKglue` 都继续走普通 leaders 路径；
  不再为胶水另画水平线，也不让波浪与斜删除线采用不同的接点规则。
- `underwave/symbol` 只有保持默认值时才进入上述周期路径。用户自定义波浪符号继续
  使用历史 `\xleaders` 路径，其尺寸、相位和视觉结果由使用者检查。
- `l3draw` 会把负纵坐标归一化为盒子高度，绘图盒本身的 depth 因而是零。默认斜线
  绘制成约 `.93em` 高，再整体下移 `.09em`，使可见范围约为基线下 `.09em` 至基线
  上 `.84em`，覆盖常见全角汉字的深度和高度。

## 验证

测试按职责分层：

1. `fntef-underline-offset` 使用真正的 `l3draw` 装饰盒，固定 8pt、10.53937pt 和
   15pt 下的宽、高、深，证明周期宽度确为 `1em/4`、斜线约高 `.93em`，并随字号缩放。
2. 节点和换行回归把完整绘图换成同尺寸的轻量规则盒子，固定默认与自定义 leader
   类型、裁切结构、两种端点形式、相邻命令、标点、换行、实际伸缩的 `CJKglue` 和
   显式 `\quad`；另检查断行前后 PDF 图形状态分别闭合，正文节点、行宽、断点和
   glue set 不变。
3. `fntef-phase01` 先从 XDV 生成不压缩内容流的 PDF，再由
   `testfiles/support/fntef-phase-check.lua` 读取标记与图案盒的实际横坐标。它固定
   所有周期盒处在同一个普通 leaders 网格、普通与带 `-` 形式分别对称外伸／内缩
   半周期、每个普通命令只有一段连续覆盖、固定和伸缩 `CJKglue` 连续、相邻带 `-`
   命令恰有一个周期断口，以及普通显式跳距仍被装饰。
4. 从手册提取的单页 MWE 检查实际字体、字号、示例文字和伸缩胶水下的波浪形状、
   斜线纵向覆盖、密度、连接、装饰长度和居中；整本文档构建只验证集成路径。

从源码树验证生成宏包时，必须在编译日志中核对实际加载的 `xeCJKfntef.sty` 路径。
系统 TeX Live 中的同名旧文件不能作为当前工作树实现的证据。

## 与 #1017 的职责边界

本决定只处理默认装饰图案的几何和随字号缩放。#1017 在共享装饰盒中使用空
`ActualText`，并在最小范围暂停 tagging，负责 PDF 的复制、搜索和文本提取语义；
boundary capture 的暂停／恢复负责 xeCJK 命令边界状态。三条路径解决不同问题，
都要保留各自的回归。

普通 PDF 和启用 tagging 的同一最小样例经 `pdftotext -raw` 与 `-layout` 提取时都只
包含正文，说明本次几何改动没有破坏 #1017 建立的文本语义隔离。

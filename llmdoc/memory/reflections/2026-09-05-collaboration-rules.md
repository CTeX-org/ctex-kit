# 协作规则正文与授权边界（2026-09-05）

提交 `03601e49af3c5f0a024ab0156db006793519a809` 将仓库根目录的协作约定整理为唯一规则正文：`CLAUDE.md` 是规范来源，`AGENTS.md` 只是指向它的兼容符号链接，不应被当作第二份需要同步维护的规则。更深目录中的规则文件仍可按路径补充或覆盖根规则。

本次还明确区分了两类授权：用户允许在工作树中编辑本地文档，不等于允许 commit、push、创建或更新 PR；只有用户明确授权这些外部写入，或任务本身明确要求完成远端闭环时，才能执行。由此，后续文档同步任务应把“允许修改哪些文件”和“允许执行哪些远端操作”分别核对，不能从前者推导后者。

这次变化没有改变 TeX 排版、构建或 CI 的运行语义；它属于仓库协作与自动化操作边界，适合记录在 Git 约定文档，而不是扩展包架构说明。
